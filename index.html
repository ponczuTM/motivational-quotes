Ładowanie tekstów z Firebase…

Panel korzysta wyłącznie ze ścieżki motivational_texts. Dostęp do odczytu i zapisu określają reguły Realtime Database Firebase — nie udostępniaj bazy publicznie do zapisu. Klucz Firebase w aplikacji klienckiej nie jest hasłem ani uprawnieniem administratora.

Połączenie z Firebase

Ustawienia są zapisywane lokalnie w tej przeglądarce. Firebase Web API key jest identyfikatorem projektu, a nie sekretem. Zabezpiecz dostęp regułami Realtime Database i ogranicz dostęp do zaufanych użytkowników.
